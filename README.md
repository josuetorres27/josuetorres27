## Featured Work

- **[CS Interactive Workshop](https://workshop.josuetorressibaja.com/):** Interactive Computer Science learning platform for UCR students with 12 stations covering algorithms, data structures, parallel/concurrent programming, TCP/IP sockets, classic coding problems, and SQL through live browser simulations backed by native C11/C++17 engines ([GitHub Repository](https://github.com/josuetorres27/cs-interactive-workshop)). Deployed live on Google Firebase Hosting with Cloud Firestore cloud progress sync, backed by more than 1,300 automated tests in CI/CD, and developed through agentic AI & prompt-engineering workflows.
- **[Interactive Portfolio & Retro Companion](https://josuetorressibaja.com/):** Personal portfolio featuring a custom pixel-art interactive guide, procedural 8-bit audio synthesis via Web Audio API, dual-language architecture (EN/ES), and zero-build static performance.
- **[PAdES-LTA Renewer](https://github.com/josuetorres27/pades-lta-renewer)** *(Oct 2026 – Present · UCR)*: Research project for CI-0140 Software Quality — an engine and web service that renews timestamps on digitally signed PDF documents for long-term preservation (PAdES-B-LTA / ETSI EN 319 142), in line with Costa Rica's Law 8454. Built with Python, Flask, cryptography, asn1crypto, pypdf, RFC 3161, X.509, OCSP/CRL, and pytest; co-authored with Gabriel Serrano Rojas.
- **[LASCE — Institutional Scientific Web Platform](https://lasce.ucr.ac.cr):** Full-stack institutional CMS and observatory data visualization developed for the Solar Astrophysics and Space Weather Laboratory (UCR) ([GitHub Repository](https://github.com/LasceUCR/lasce)), built with Next.js 16, React 19, Prisma ORM, PostgreSQL, Redis, BullMQ, MinIO, and Playwright.
- **[Virtual Microscope Administration Panel](https://github.com/RolandoVillavicencio013/biological-microscope-administration-panel):** Desktop administration platform that digitizes microscopy workflows and manages biological specimen collections, built with C#, ASP.NET Core, .NET, and PostgreSQL.
- **ThemePark UCR — Virtual University Simulation:** Virtual campus simulation built in Unity with decoupled RESTful APIs, C#, and SQL Server.
