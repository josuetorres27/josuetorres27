## Featured Projects

- **CS Interactive Workshop:** Interactive Computer Science learning platform for UCR students with 13 stations covering algorithms, data structures, parallel/concurrent programming, TCP/IP sockets, classic coding problems, SQL, and Git through live browser simulations backed by native C11/C++17 engines. Deployed on Google Firebase Hosting with Cloud Firestore cloud progress sync, backed by 1,538 automated tests in CI/CD, and developed through agentic AI and prompt-engineering workflows. [Live App](https://workshop.josuetorressibaja.com/) · [Repository](https://github.com/josuetorres27/cs-interactive-workshop)
- **Mi VuelTica:** Mobile app (iOS, Android, and web) for discovering free and low-cost places and events in Costa Rica, with community reviews, verifications, and vote-based moderation; started in a course by a team of five, which keeps developing it. As the team's full-stack integrator, I connected the Expo/React Native app to the Express/Prisma REST API (reputation, community moderation, reviews, reports, blocking, and photo uploads), implemented privacy consent under Costa Rica's Law 8968, designed fail-open AI pre-moderation (OpenAI moderation plus a local spam check), fixed a rate-limit bypass and a default JWT secret in production, built push notifications end to end, and set up CI (lint, type checks, Jest, and Playwright) and EAS release builds, reviewing and merging 26 pull requests. Built with AI-assisted development (Claude Code) under my own review. [App](https://github.com/MiVuelticaApp/mi-vueltica-app) · [API](https://github.com/MiVuelticaApp/mi-vueltica-api) · [Website](https://github.com/MiVuelticaApp/mi-vueltica-web)
- **Interactive Portfolio & Retro Companion:** Personal portfolio featuring a custom pixel-art interactive guide, procedural 8-bit audio synthesis via Web Audio API, and an English page and a Spanish page pre-rendered with Astro and Tailwind CSS. [Live App](https://josuetorressibaja.com/) · [Repository](https://github.com/josuetorres27/portfolio)
- **PAdES-LTA Renewer:** Research project for CI-0140 Software Quality at the University of Costa Rica: an engine and web service that renews timestamps on digitally signed PDF documents for long-term preservation (PAdES-B-LTA / ETSI EN 319 142), in line with Costa Rica's Law 8454. Built with Python, Flask, cryptography, asn1crypto, pypdf, RFC 3161, X.509, OCSP/CRL, and pytest; co-authored with Gabriel Serrano Rojas. [Repository](https://github.com/josuetorres27/pades-lta-renewer)
- **Virtual Microscope Administration Panel:** Desktop administration platform that digitizes microscopy workflows and manages biological specimen collections, built with C#, ASP.NET Core, PostgreSQL, JavaScript, and HTML/CSS.
