## Featured Projects

- **CS Interactive Workshop:** Interactive Computer Science learning platform for UCR students with 12 stations covering algorithms, data structures, parallel/concurrent programming, TCP/IP sockets, classic coding problems, and SQL through live browser simulations backed by native C11/C++17 engines. Deployed on Google Firebase Hosting with Cloud Firestore cloud progress sync, backed by 1,376 automated tests in CI/CD, and developed through agentic AI and prompt-engineering workflows. [Live App](https://workshop.josuetorressibaja.com/) · [Repository](https://github.com/josuetorres27/cs-interactive-workshop)
- **Interactive Portfolio & Retro Companion:** Personal portfolio featuring a custom pixel-art interactive guide, procedural 8-bit audio synthesis via Web Audio API, dual-language architecture (EN/ES), and zero-build static performance. [Live App](https://josuetorressibaja.com/) · [Repository](https://github.com/josuetorres27/portfolio)
- **PAdES-LTA Renewer:** Research project for CI-0140 Software Quality at the University of Costa Rica: an engine and web service that renews timestamps on digitally signed PDF documents for long-term preservation (PAdES-B-LTA / ETSI EN 319 142), in line with Costa Rica's Law 8454. Built with Python, Flask, cryptography, asn1crypto, pypdf, RFC 3161, X.509, OCSP/CRL, and pytest; co-authored with Gabriel Serrano Rojas. [Repository](https://github.com/josuetorres27/pades-lta-renewer)
- **LASCE — Institutional Scientific Web Platform:** Full-stack institutional CMS and observatory data visualization developed for the Solar Astrophysics and Space Weather Laboratory (UCR), built with Next.js 16, React 19, Prisma ORM, PostgreSQL, Redis, BullMQ, MinIO, and Playwright. [Live App](https://lasce.ucr.ac.cr/) · [Repository](https://github.com/LasceUCR/lasce)
- **Virtual Microscope Administration Panel:** Desktop administration platform that digitizes microscopy workflows and manages biological specimen collections, built with C#, ASP.NET Core, .NET, and PostgreSQL. [Repository](https://github.com/RolandoVillavicencio013/biological-microscope-administration-panel)
- **ThemePark UCR — Virtual University Simulation:** Virtual campus simulation built in Unity with decoupled RESTful APIs, C#, and SQL Server.
